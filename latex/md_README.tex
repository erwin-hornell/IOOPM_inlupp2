Inlupp 1 is a C library created as part of the course Imperativ och objektorienterad programmeringsmetodik (1DL221), HT2026.\hypertarget{md_README_autotoc_md1}{}\doxysection{\texorpdfstring{The project contains\+:}{The project contains\+:}}\label{md_README_autotoc_md1}
A shop system for an online store, which allows adding/editing items in a database, setting their stock, creating shopping carts, and checking out said carts (the system ensures the cart order can be satisfied and depletes stock). Created by Erwin Hörnell and Leonard Öhrström.\hypertarget{md_README_autotoc_md2}{}\doxysection{\texorpdfstring{Requirements}{Requirements}}\label{md_README_autotoc_md2}

\begin{DoxyItemize}
\item A shop holds a database and carts, and coordinates them.
\item Coupling between db and cart modules has been kept minimal.
\item A database keeps track of item types, as well as their stock (if any).
\item A cart keeps track of item types and amount added to it.
\item An item contains a name, a description and a price.
\item The database owns item types. The cart borows them.
\item A cart does not know if its order can be fulfilled -\/ will be denied by shop if stock insufficient.
\item The header file utils.\+h holds functions and types specific only relevant for this particular program which must be available to multiple modules for smooth integration.
\item The header file string\+\_\+utils.\+h holds general functions for reading terminal input.
\item list\+\_\+structs holds modules for hash tables, linked lists, and iterators. The modules are from \href{https://github.com/erwin-hornell/IOOPM_inlupp1}{\texttt{https\+://github.\+com/erwin-\/hornell/\+IOOPM\+\_\+inlupp1}}.
\end{DoxyItemize}\hypertarget{md_README_autotoc_md6}{}\doxysection{\texorpdfstring{Cleaning generated files}{Cleaning generated files}}\label{md_README_autotoc_md6}
